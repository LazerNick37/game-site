Bun's Sanctuary

Saving has been added in the 0.0.02 version!

Bun's Sanctuary is an incremental game which combines bullet heaven and collection mechanics. The goal of the game is to make it to the deepest part of the ocean, and collect as many unique fishes along the way.

This demo version currently features :

  • a first zone with 3 levels
  • 6 unique fishes that you can acquire in 5 different rarities, which grant you various traits
  • ~20 upgrades in a skill tree
  • 3 different weapons

Thanks for playing, and any feedback is greatly appreciated!
